# 🌙 dream: the zero `cache.set` rate prints at 2 places beside 9-place peers

kind: fix · owner: rhachet-brains-openrouter · caught 2026-10-22

## .the cue that fired

a live raw-i/o capture (5.3 self review `has-ergonomics-validated`) showed
`"cache": { "get": "USD 0.000_000_000", "set": "USD 0.00" }`.

## .the gap, precisely

`set: asIsoPrice('$0')` in `BrainAtom.config.ts` (pro, flash) and `slug/AtomSlug.unlisted.ts` holds
2 decimals. each peer rate is `priceDivide({ of: '$X', by: 1_000_000 })`, which holds 9. so
`rate × tokens` prints `USD 0.00` for set and `USD 0.000_000_000` for get. same value, two shapes.

## .the shape of the fix

`set: priceDivide({ of: '$0.00', by: 1_000_000 })` in the three spots. resnap
`index.unit.test.ts.snap` (the spec string changes). run the live config probe, since
`BrainAtom.config.ts` is touched.

## .why it is not done in this round

it was done, then reverted at 5.3 i004: a peer review held that it changes a string in the
published spec that every consumer reads, and no feature on this branch needs it. it belongs in its
own small fix release.
