# 🌙 dream: prove brain discovery in acceptance, outside jest's vm

kind: fix · owner: rhachet-brains-openrouter · caught 2026-10-02

## .the cue that fired

acceptance `[case1b] a tier chosen by discovery, as the readme shows` failed with
`BrainChoiceNotFoundError ... available brains (none)`. the stdout log held the cause:

```
💥 could not load brain package "rhachet-brains-openrouter": TypeError
[ERR_VM_DYNAMIC_IMPORT_CALLBACK_MISSING_FLAG]: A dynamic import callback was invoked
without --experimental-vm-modules
```

the same error hit `rhachet-brains-anthropic`, so every package failed to load, not just ours.

## .the gap, precisely

- rhachet's `getAvailableBrains` loads each `rhachet-brains-*` package via
  `importPackageExports`, a dynamic `import()` (esm-safe)
- jest runs tests inside a node vm; a dynamic `import()` there needs
  `--experimental-vm-modules`, else it throws, and rhachet degrades the package to no brains
- ⇒ discovery cannot be proven from inside jest as configured. the product path (plain
  node) is unaffected; the readme's discovery example has no live proof
- case1b is `given.skip` until this lands

## .the shape of the fix

pick one:

1. **child process (preferred)** — run discovery the way a consumer does, in plain node,
   as `readme.acceptance.test.ts` already runs the readme probe:
   `execFileSync('node', ['-e', body], { cwd: REPO_ROOT, env: { ...process.env } })`,
   where `body` requires `rhachet`, calls
   `genContextBrain({ choice: { atom: 'openrouter/deepseek/flash' }, creds })`, asks once,
   and prints `brain.choice.slug` plus the output. assert on stdout. then un-skip case1b
2. **jest flag** — run the acceptance suite under
   `NODE_OPTIONS=--experimental-vm-modules`. broader blast radius: every acceptance test
   then runs with esm vm semantics
3. **reseed rhachet** — ask `ehmpathy/rhachet` whether `importPackageExports` can fall back
   to `require()` for a cjs package when `import()` is unavailable

## .why it is not done in this round

the wisher called for a release asap and ruled: skip the discovery test for now, catch it
as a dream. the fix is test-harness work only; it ships no product change.
