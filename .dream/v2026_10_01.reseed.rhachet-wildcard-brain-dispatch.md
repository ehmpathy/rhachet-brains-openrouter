# 🌙 dream: rhachet routes a brain choice to a wildcard atom

kind: reseed
owner: ehmpathy/rhachet
caught: 2026-10-01, from `rhachet-brains-openrouter` route `v2026_09_30.feat-openrouter-brains`
dispatched: ehmpathy/rhachet#574, 2026-10-02, at the wisher's ask

## .the cue that fired

the wisher ruled that `rhachet-brains-openrouter` must reach any openrouter model with no
per-model edit and no release: *"eliminate the need for constant updates"*. then:
*"publish an openrouter/{manufacturer}/{model}/{filters} where manufacturer can be * and model
can be * ; e.g., openrouter/*/*/* and expect that rhachet will know to route brains to it,
wildcard style."*

the package can publish that atom today. rhachet cannot route a choice to it.

## .the gap, precisely

read 2026-10-01, `rhachet@1.48.0` `dist/domain.operations/context/genContextBrain.js`:

- lines 79, 92, 103 — every choice form matches by string equality:
  `getBrainSlugFull(a) === choice`. a choice `openrouter/z-ai/glm-5.3/floor` never equals
  `openrouter/*/*/*`, so the caller gets `BrainChoiceNotFoundError`
- `asBrainsFromPackageExports` calls each `getBrainAtomsBy*` synchronously and keeps it only if
  `Array.isArray` — so a package cannot enumerate models it learns about at runtime
- `BrainAtom.spec` is static and set at construction; a wildcard atom cannot know the context
  window or rates of the model a caller names until it is told which one

⇒ three gaps, one root: the registry assumes a **finite, closed** set of slugs. a router
package's set is open.

## .the shape of the fix

0. **a pattern is a routing claim, never a brain.** the wisher, 2026-10-01: *"we just say even
   if you havent seen `openrouter/newcompany/newmodel`, send it our way and we may resolve it."*
   so a package declares patterns beside its atoms; no caller selects a pattern, the registry
   lists no pattern as an atom, and a choice of the literal pattern string is refused.
1. **a declared pattern matches by segment.** a `*` segment matches exactly one non-empty
   segment of a choice. so `openrouter/*/*/*` matches `openrouter/a/b/floor&region=usa`. a choice
   with no filter segment (`openrouter/a/b`) matches the second declared pattern
   `openrouter/*/*` — the wisher wants both routed (2026-10-01), and two exact-length patterns
   keep the match rule simple: no optional segments.
2. **exact beats pattern.** `genContextBrain` tries exact matches first (today's behavior,
   unchanged), then patterns. more literal segments wins. two patterns that tie on one choice
   = `ConstraintError` at registry build, the same as a duplicate atom today.
3. **the pattern hands the concrete slug to the package.** a declared pattern carries
   `genAtomFor({ slug }) → BrainAtom | Promise<BrainAtom>` (name open). rhachet calls it with
   the caller's choice and uses the atom it returns, whose `slug` is the choice verbatim
   (`rule.require.versionless-slugs-selectable`: the atom keeps the name the consumer holds).
   it may throw a `ConstraintError` — a malformed filter, or an id the provider lacks, with the
   nearest ids suggested — and that surfaces as-is, never as "not found".
4. **let it await.** 🟡 the sharpest ask. if `genAtomFor` may be async, the package reads the
   model's catalog entry (cached) before it builds the atom, so `spec` carries the model's true
   rate and context window, not a placeholder. if it must be sync, `spec` on an atom built from
   a pattern is a labelled estimate — rhachet's `BrainSpec` may want an explicit `unknown` rate
   rather than a fake number. (openrouter route Q26.)
5. **`BrainChoiceNotFoundError` names the declared patterns** a choice failed to fit, so a
   caller who mis-shapes a slug sees the shape that would have been routed.

clamps owed upstream: exact-wins-over-pattern; one-segment match per `*`; tie refused at build;
a pattern never listed or chosen as a brain; `genAtomFor` error surfaces unwrapped; the
returned atom's `slug` equals the choice.

## .why it is not done in this round

it is another repo's contract (`rule.always.catch-dreams-for-followups`: a tree adopts only
what is scoped to itself). this package's half is clean and ships now: it declares
`openrouter/*/*/*` with its atom builder already present, so when rhachet learns the route, no
release of this package is owed (unless the hook's shape differs from the one sketched here). until then a caller reaches any id via direct
`genBrainAtom({ slug })`, and reaches the curated static atoms by name.
