# 🌙 dream: each floor hop records its evidence — time, cost, and the upstream message

- kind: feat
- owner: rhachet-brains-openrouter
- caught 2026-10-21, on `beav/feat-thought-cap-and-host-sort` (r011 i008, nitpick.1)

## .the cue that fired

a reviewer showed `FloorAttempt` is `{ tag, outcome }`: a label with no evidence. on a walk, a host the walk stepped past may bill (issue #24: 24–28k output tokens per empty reply), yet `cash.total` holds the served reply's charge alone, while `cost.time` spans every hop. a 5xx that steps keeps only the label `failed`, with its upstream message dropped.

## .the gap, precisely

- a caller cannot see what a walk spent, only what the served reply cost
- a request-induced 5xx reads "each failed", with no cause
- F11's per-hop bound has no per-hop timing to tune from

## .the shape of the fix

add `ms`, `costUsd: number | null` and `message: string | null` to `FloorAttempt`. each one is already on the hop verdict (`getOneHopVerdict`). then:

- `supply.attempts` shows each hop's spend and cause;
- the readme states the walk total as the sum of the hops;
- `getOneFloorExhaustedError` prints the message beside each `failed` row.

it is a report-shape change, so the acceptance snaps move.

## .why it is not done in this round

it changes the public report shape a third time in one release, and the sibling 429 tree edits the walk's file. the readme now states the gap (`cash.total` is the served reply alone).
