# 🌙 dream: a brain output names who served it

kind: reseed
owner: ehmpathy/rhachet (type), ehmpathy/rhachet-roles-bhrain (review logs)
caught: 2026-10-01, from `rhachet-brains-openrouter` route `v2026_09_30.feat-openrouter-brains`

## .the cue that fired

the wisher asked: *"does it make it super clear in the output meta what exactly the supplier of
the brain was?"* — it does not, past the atom.

## .the gap, precisely

- `rhachet@1.48.0` `BrainOutputMetrics` declares `size` and `cost` only. a router atom
  (openrouter) serves each ask from one of ~30 hosts; which one is the fact a caller most needs
  to audit price, privacy, and region. this package puts it in `metrics.route` — untyped, so a
  caller reads it only through a cast
- `rhachet-roles-bhrain@0.38.0` `dist/domain.operations/review/stepReview.js:681-703` copies
  `metrics.size.*`, `metrics.cost.cash.*`, `metrics.cost.time` field by field into its log. any
  other field — `route` among them — is dropped. a review log shows a charge and never who
  earned it

measured live 2026-10-01: the same prompt, bare slug → AtlasCloud (off the zdr list) at
$0.0000556; floor slug → Morph (zdr) at $0.0000092. a review log could not tell the two apart.

## .the shape of the fix

1. rhachet: `BrainOutputMetrics` gains an optional `served` (name open):
   `{ provider: string; endpoint: string | null; generationId: string | null }`. a direct-model
   supplier leaves it null; a router fills it
2. bhrain: `stepReview` logs `metrics.served` beside cost, and the review output header names
   it: `brain: openrouter/deepseek/flash/floor&… → Morph (morph/fp8)`
3. this package then moves `metrics.route.{provider,generationId}` onto the typed field; keeps
   `attempts` and `costUsd` as router detail

## .why it is not done in this round

two other repos' contracts. this package already returns the facts; it cannot make an
upstream type or log carry them.
