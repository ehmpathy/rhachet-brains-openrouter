# 🌙 dream: split the flat `supply/` dir into reply · hop · filters · funnel clusters

- kind: refactor
- owner: rhachet-brains-openrouter
- caught 2026-10-21, on `beav/feat-thought-cap-and-host-sort` (r011 i008, nitpick.6)

## .the cue that fired

`src/domain.operations/supply/` holds 44 prod files in one flat dir. the thought cap spans `atom/`, `supply/`, `infra/cast` and `domain.objects`.

## .the gap, precisely

a reader cannot see which files read a reply, which run a hop, which parse filters, and which build the funnel (`rule.prefer.directory.subdomain-clusters`).

## .the shape of the fix

- `supply/reply/`: `isReply*`, `asReplyChoice`, `getOneReplyDefectError`, `isJsonText`
- `supply/hop/`: `getOneCompletionWithinBound`, `getOneFloorCompletion`, `asHostFailure`, `getOneAdmittedSetCompletion`, `getOneCompletionFromEndpoint`
- `supply/filters/`: `asSupplyFilters`, `asSlugParts`, `isSortOnlyFilters`
- `supply/funnel/`: `getAllQualifiedEndpoints`, `getOneNoQualifiedEndpointError`, `asRankedReport`
- a `thought/` cluster for `asThoughtLevel`, `asTokensThoughtBudget`, `isThoughtCapIgnored`

each move is a pure path change, run with `mvsafe` and `sedreplace`.

## .why it is not done in this round

two sibling trees (`beav/feat-latency-filter`, `beav/fix-429-hop-and-tier-fallback`) edit these same files. a move now doubles their conflicts. lift after they merge.
