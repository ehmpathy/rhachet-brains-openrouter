# 🌙 dream: jest testMatch excludes `.agent/` in the declapract template

kind: reseed
owner: ehmpathy declapract best-practices (the jest.*.config.ts templates)
caught: 2026-10-02, from `rhachet-brains-openrouter` route `v2026_09_30.feat-openrouter-brains`

## .the cue that fired

`rhx git.repo.test --what unit --scope path://src/domain.operations/route` matched
`.agent/.cache/repo=ehmpathy/role=mechanic/skill=rmsafe/trash/src/domain.operations/route/asCacheEntry.test.ts`
— a test deleted via `rmsafe` minutes before, still run from rmsafe's trash bin.

## .the gap, precisely

the three jest configs' `testMatch` exclude only `!**/.yalc/**`. `.agent/.cache/` sits inside the
repo and holds copies of source files (rmsafe trash; other skills' caches), so a deleted test
keeps to run — and can keep a suite green or red on code that no longer exists.

## .the shape of the fix

add `'!**/.agent/**'` to `testMatch` in `jest.unit.config.ts`, `jest.integration.config.ts`, and
`jest.acceptance.config.ts` in the declapract template. applied locally in this repo already;
the template must carry it, or the next `declapract.upgrade` reverts it.

## .why it is not done in this round

it is another repo's template. the local fix landed here (safe and clean); only the upstream
half is deferred.
