## .the cue that fired

this route's reviewers timed out on the fireworks default and were swapped by hand to
`--brain openrouter/deepseek/flash` in the route's guard. then the wisher asked why those calls
"just got the most expensive provider". the measured answer: the bare slug went through
openrouter's balancer, 1.4–4.9× the cheapest healthy host, and partly to an endpoint off the
zero-retention list.

## .the gap, precisely

- `DEFAULT_BRAIN` and `FIXED_FALLBACK_BRAIN` in `rhachet-roles-bhrain` name a fireworks slug
  (see `rule.require.pin-explicit-model-ids` in the openrouter repo for the 2026-08 incident
  that cited them).
- every repo whose guards omit `--brain` inherits it.

## .the shape of the fix

once `rhachet-brains-openrouter` publishes the cheapest-first walk (F3, F10):

1. set `DEFAULT_BRAIN = 'openrouter/deepseek/flash/floor&speed=min50tps&privacy=full'` — cheap,
   not a crawl host, never retained. reviewers send whole diffs; zero retention is the right
   default for code.
2. add `rhachet-brains-openrouter` as a dependency so `genContextBrain` discovers it.
3. keep a fallback on a second provider family, so one provider's outage does not stall every
   reviewer at once.

clamp: a test that `DEFAULT_BRAIN` is a slug the registry can select (via `genContextBrain`),
not merely one `genBrainAtom` accepts.
