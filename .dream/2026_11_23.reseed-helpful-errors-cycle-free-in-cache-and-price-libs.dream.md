# 🌙 dream: release iso-price + the cache libs onto a cycle-free helpful-errors

kind: reseed · owner: ehmpathy (iso-price, with-simple-cache, simple-on-disk-cache, with-bottleneck, simple-in-memory-cache) · caught 2026-11-23

## .the cue that fired

`rhachet-brains-openrouter`'s declapract upgrade adds `test:lint:cycles` (dpdm, `exclude: []`). it fails on `helpful-errors@1.5.3`'s `HelpfulError.js` ↔ `withHelpfulError.js` require cycle, reached from prod `src` through four prod dependencies.

## .the gap, precisely

`helpful-errors` fixed the cycle in 1.7.x (`withHelpfulError` lives inside `HelpfulError.ts`). the latest release of each package below still pins a chain that ends at 1.5.3:

| package | latest | pins |
|---|---|---|
| `iso-price` | 1.2.0 | `helpful-errors@1.5.3` |
| `with-simple-cache` | 0.17.3 | `simple-in-memory-cache@0.4.2` |
| `simple-on-disk-cache` | 1.8.1 | `simple-in-memory-cache@0.4.2` |
| `simple-in-memory-cache` | 0.5.1 ✅ | `helpful-errors@1.7.3` — already clean |
| `with-bottleneck` | 0.1.2 | `domain-objects@0.31.13` — check its `helpful-errors` |

evidence: `pnpm why helpful-errors@1.5.3 --prod` in `rhachet-brains-openrouter` on `beav/feat-declapract-upgrade`.

every consumer that adopts the dpdm practice and imports any of these packages hits the same red lint. `rhachet-roles-ghlitch` already worked around it by excludes of prod deps in `.dpdmrc.yaml`, which `rule.forbid.dpdm-exclude-change` forbids.

## .the shape of the fix

1. `iso-price`: bump `helpful-errors` 1.5.3 → 1.7.6; release
2. `simple-on-disk-cache`: bump `simple-in-memory-cache` 0.4.2 → 0.5.1 (and `with-bottleneck` if it still reaches 1.5.3); release
3. `with-simple-cache`: bump `simple-in-memory-cache` → 0.5.1 and `simple-on-disk-cache` → the step-2 release; release
4. here: bump `iso-price`, `with-simple-cache`, `simple-on-disk-cache`, `rhachet-artifact` (→ 1.0.4); `test:lint:cycles` should then pass the prod path
5. then `rhachet-roles-ghlitch` can drop its prod-dep excludes

the dev path (`rhachet` → `declastruct-aws@1.5.2` → `@aws-sdk` cycles) is a separate thread: `rhachet` declares a peer of `declastruct-aws@>=1.10.1` yet pins 1.5.2.

## .why it is not done in this round

safe, but not clean: it ripples into four other repos and four releases. this route may not commit, let alone release elsewhere. the call between "wait for upstream" and "accept an exception" belongs to the wisher — fulcrum F1.
