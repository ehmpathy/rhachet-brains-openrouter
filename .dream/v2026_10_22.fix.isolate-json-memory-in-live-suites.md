# 🌙 dream: isolate the 7-day json memory in the live suites, in place of a mask

kind: fix · owner: rhachet-brains-openrouter · caught 2026-10-22

## .the cue that fired

peer review 5.3 i004 (r012 nitpick.4): the live snaps in `genBrainAtom.supply.integration.test.ts`
and `getBrainAtomsByOpenRouter.acceptance.test.ts` drop any `honors(json)` funnel step, since the
step shows only when this machine's 7-day memory holds a host. so those suites cannot see the step.

## .the gap, precisely

the step is built only when `tagsJsonIgnored.length > 0`, read from on-disk memory. a dev machine
and a clean CI machine snap different funnels. the mask makes them agree, and blinds both.

## .the shape of the fix

give each live suite its own empty memory dir (a temp dir per run, via whatever seam the memory
reads its root from; add one if none exists). then drop the mask, and add one live case that seeds
a host into the memory and asserts the step appears.

## .why it is not done in this round

it needs a new seam on the memory's root path, which ripples into the supply cache. the step's own
behavior is unit-tested in `getAllQualifiedEndpoints.test` ("a json-memory step that empties the set").
