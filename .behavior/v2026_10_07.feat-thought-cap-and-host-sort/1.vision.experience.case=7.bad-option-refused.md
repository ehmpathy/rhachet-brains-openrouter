# case=7 — a malformed effort or sort is refused before any spend

sharp × alterpath. it demos the rejection invariant behind 20 forbidden cells:
`d1=invalid` (6), `d1=level+budget` (6), `d2=invalid` (8). each is an attempt a caller can make,
and each is refused before any call.

## .narrative

a caller computes a budget from data and lands on `0`, or `-200`, or `1500.5`; or writes
`effort: 'xhigh'`, a level this brain does not list; or a slug with `sort=fast`. the ask refuses
at once, with no call sent, and names the valid shape.

## .sketch

```
✋ ConstraintError: invalid effort for openrouter/deepseek/flash { budget: { tokens: 0 } }: tokens must be a positive integer

valid shapes, one of:
  - effort: 'minimal' | 'low' | 'medium' | 'high'   (≡ { level: … })
  - effort: { budget: { tokens: N } }              N a positive integer
```

## .timeline

```
given('[case7] an ask with a malformed option')
  when('[t0] effort.budget.tokens = 0 | -200 | 1500.5, or effort = "xhigh" | "max" | "none"')
    then('the ask rejects with a ConstraintError before any network call')
    then('the error lists the valid shapes, with the levels from spec.supports.effort.levels')
  when('[t1] effort holds both level and budget (a cast past PickOne)')
    then('the ask rejects: openrouter takes one, not both')
  when('[t2] the slug holds sort=fast')
    then('the atom refuses at build, before any ask, and lists sort=price|throughput|latency')
```
