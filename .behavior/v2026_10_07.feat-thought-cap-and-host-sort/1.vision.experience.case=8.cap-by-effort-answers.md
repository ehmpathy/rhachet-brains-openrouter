# case=8 — a cheap verdict sets its effort by level, and answers

happy × alterpath. cell: `d1=level=E × d6=qualified × d4=answered`.

## .narrative

a lint-style review lane needs only a shallow look. bhrain does not know a sensible token count
for every model it may reach, so it asks by level: `effort: 'low'`. the body carries
`reasoning.effort`, never `max_tokens`, and only hosts that list `reasoning` are admitted. the
reply answers, and `metrics.size.tokens.thought` shows how much `low` bought on this model, so
bhrain can move to a token budget once it has the data.

## .sketch

```ts
const result = await choice.ask({ ...input, effort: 'low' }); // ≡ { level: 'low' }
result.metrics.size.tokens.thought; // 900
```
