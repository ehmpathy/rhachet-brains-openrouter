# case=6 — no qualified host honors an effort

sharp × alterpath. cells: `d1=budget=N × d6=none-qualify × d4=any` (3; the level twin is itemized).

## .narrative

a caller sets an effort on a model whose hosts do not list the `reasoning` param. a silent
forward would let a host ignore the budget and think to the limit — the exact harm the budget
exists to stop. so `reasoning` joins the params a host must list, the same way `response_format`
does for a json ask. no host qualifies; the extant funnel error fires before any spend, and its
funnel names `reasoning` as the param that emptied the set.

## .timeline

```
given('[case6] a model whose every host lacks the `reasoning` param')
  when('[t0] the ask sets effort.budget.tokens = 4000')
    then('no completion is sent')
    then('the error names `reasoning` as the absent param, and the hosts it excluded')
    then('the fix names: drop the effort, or choose a model whose hosts list reasoning')
```
