# case=1 — a review ask budgets its thought by tokens, and answers

happy × critipath. cell: `d1=budget=N × d4=answered`.

## .narrative

bhrain's `stepReview` has a 90s deadline and a verdict that needs ~800 output tokens. it asks
the flash tier to think up to 6000 tokens, then answer. the host thinks 4100 tokens, writes the
verdict, and stops. the reply carries the verdict, and `metrics.size.tokens.thought = 4100`.
after a week of such replies, bhrain reads the spread and lowers its budget to 5000 — from data,
not a guess.

## .sketch

```ts
const result = await context.brain.brain.choice.ask({
  role: {},
  prompt,
  schema: { output: verdictSchema },
  effort: { budget: { tokens: 6000 } },
});
result.output;                      // the verdict
result.metrics.size.tokens.thought; // 4100
```
