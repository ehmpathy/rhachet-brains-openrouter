# experience dimensions — thought cap + host sort

## .the actors

| actor | meets the behavior as | where |
|---|---|---|
| **caller** — code that asks (measured: bhrain's `stepReview`) | sets `effort` on the ask, picks a slug, reads `metrics.size.tokens.thought` and the supply report | case=1, 4, 5, 6, 7, 8 |
| **on-call engineer** — reads the error a caller throws | reads the all-thought error, the funnel, the refusal | case=2, 6, 7 |
| **0.1.3 consumer** — upgrades and sets naught | sees an unchanged body and host order | case=3 |

actor is not a product axis: each actor meets one fixed slice of the axes, named in `where`.

## .the dimensions — each a closed set

| # | dimension | positions |
|---|-----------|-----------|
| d1 | effort (the thought cap, on the ask) | `unset` · `budget=N` (N a positive integer) · `level=E` (E ∈ `spec.supports.effort.levels` = `minimal` · `low` · `medium` · `high`; the string alias `'E'` reads as `{ level: 'E' }`) · `level+budget` · `invalid` (N ≤ 0, N not an integer, E outside the listed four, incl. openrouter's `xhigh` · `max` · `none` — F07) |
| d6 | host admission | `qualified` (≥ 1 host keeps every promise) · `none-qualify` (the funnel empties: no host lists `reasoning`, or the budget ≥ every host's `max_completion_tokens`) |
| d4 | reply outcome | `answered` · `thought-exhausted` (length, empty answer) · `answer-cut` (length, partial answer) |
| d2 | host sort (a slug word) | `unset` · `price` · `throughput` · `latency` · `invalid` |
| d3 | supply mode | `floor` (default: walk one host per hop) · `admitted-set` (a filter segment that holds no `floor` word and some word other than `sort=`). a segment that holds only a sort word merges onto the default, so it is `floor` (F28): `…/flash/sort=throughput` walks the floor and keeps every default promise |
| d5a | affinity pin (prompt-cache tree) | `absent` · `present` |
| d5b | latency filter (latency tree) | `absent` · `present` |
| d7 | host fault, per hop | `sound` (the body arrives whole, inside the bound) · `body-cut` (the body ends mid-json) · `stalled` (no whole body inside the per-hop bound) · `gateway` (the host answered 502, 503 or 504; issue #12. a bare 500 is not a host fault, and rethrows as 0.1.3) · `empty-json` (`stop` with 0 chars where json was owed; issue #24) |

d5 is two independent binary levers, not one three-way choice. a caller can hold both at once.

## .precedence — one order, every combination

```
latency filter narrows the set  →  affinity pin takes the first slot, if its host survived  →  sort orders the rest
```

- **filter before pin.** a filter is a promise; a pin is a preference. a pinned host that fails
  the latency bound is excluded like any other, and the pin yields. the report names why
  (case=5 [t4])
- **pin before sort.** a cache read beats any cold host on cost and prefill (F08)

## .orthogonality — the product splits in two

- **sub-product A — the ask's body and reply:** d1 × d6 × d4 = 5 × 2 × 3 = **30 cells**. d6 sits
  between them: `none-qualify` sends no call, so it forecloses every d4 position
- **sub-product B — which host serves:** d2 × d3 × d5a × d5b = 5 × 2 × 2 × 2 = **40 cells**
- **sub-product C — a hop's fault:** d7 × d3 = 5 × 2 = **10 cells**. a fault is a fact
  about one hop, so it never changes the body (A) or the order (B); it decides only whether the
  walk steps on. d3 matters because only the floor walk holds a next hop

an effort never changes host order. a host sort never changes the body. the one link, an effort
that empties the funnel, is its own axis (d6) rather than a value smuggled into d4. the split
also matches the channels: A rides the ask, B rides the slug.

**d6 = none-qualify voids all of B.** no call is sent, so no host is chosen: every
`none-qualify × d2 × d3 × d5a × d5b` cross cell is one experience, the pre-spend funnel refusal
that case=6 demos. no sort, pin, or filter changes it, so the cross adds no cell of its own.

every cell carries a verdict in `1.vision.experience.case=_.md`.
