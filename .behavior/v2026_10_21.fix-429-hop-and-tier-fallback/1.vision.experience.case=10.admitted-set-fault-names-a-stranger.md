# case=10 — admitted set, a host fault that names a host outside the set

feel: happy · care: critipath · seats: participant

## narrative
a reviewer lane asks with A and B admitted. openrouter answers a marked 400 whose
`provider_name` is "Stranger" — a host the lane never admitted (a provider renamed upstream, or
a name that drifted from the endpoint list). a drop by that name would remove no admitted host,
and a re-send of the same set could meet the same fault: a loop. yet the marker says a host
failed, so the ask is not lost: it walks the set one host per send, as a floor walk does. each
send admits one host, so the next fault there names its host by `only`, and the walk ends in at
most one send per endpoint. A fails alone and is stepped past; B serves.

## bdd
```
given  [case10] qualified = [A, B], no floor
when   [t0] the send answers 400 marked, that names "Stranger"; A alone fails the same way
then   the ask walks the set — admits = [[A, B], [A], [B]]
then   attempts = [{ A, failed }, { B, served }]
then   B serves
```
