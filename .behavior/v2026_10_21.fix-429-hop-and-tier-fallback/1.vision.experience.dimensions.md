# 1.vision.experience.dimensions

the space every host-fault experience sits in. each axis is closed and reads its own source — the
request slug, the http status, the error message, the error's `provider_name`, the set after a
hop — so no axis value implies another's. the product is reduced, cell by cell, in
`1.vision.experience.case=_.md`.

## axes

| axis | positions | field it reads |
|---|---|---|
| **path** | floor · admitted | the slug: floor = one host admitted per hop; admitted = the whole qualified set at once |
| **status** | served · 429 · 404 · 400 · unrecognized | the http status. unrecognized = every other status (401, 402, 408, 500, 502, 503, …) — one value, since every one of them rethrows |
| **flag** | flagged · unflagged | `error.message`: is it openrouter's `Provider returned error` |
| **name** | admitted · stranger · absent | `error.metadata.provider_name`: a host in the admitted set, a host outside it, or no name |
| **left** | another · none | the set after the faulted host leaves (post-hop state, not a reply field): is a host left to send to |

`flag` and `name` read two separate fields, so all six pairs occur. a status-400 reply is
**host-marked** when `flag = flagged` OR `name ≠ absent`; else it is the caller's.

## the decision each cell reduces to

`asHostFault` reads status, flag, name:

| status | host-marked | verdict |
|---|---|---|
| 429 | either | host fault — throttled |
| 404 | either | host fault — refused |
| 400 | yes | host fault — failed |
| 400 | no (unflagged, name absent) | caller fault — rethrow |
| unrecognized | either | not a host fault — rethrow |
| served | — | no fault |

then the path decides what a host fault does:

- **floor** steps on any host fault. it admitted one host, so the fault is that host's whatever
  `name` says. `name` is inert on the floor path
- **admitted** hops when `name = admitted`: it drops that host and re-sends the rest. when the
  fault is host-marked yet `name ∈ {absent, stranger}`, it cannot say which host to drop, so it
  walks the set one host per send, as the floor path does (each send then names its host by
  `only`). when the fault carries no host mark (`unflagged` and `name = absent`), it is
  openrouter's own answer — its normalized `429 Rate limit exceeded` (the account limit), or a
  404 for a withdrawn model. no other host can fix it, so it rethrows in one send (c9)

## actors

the actor is not an axis of the product: it is the *seat* from which a cell is lived. two seats:

| seat | who | lives |
|---|---|---|
| participant | the caller (a ci suite, a reviewer lane) | every cell: the ask is served or the error lands in their hands |
| reader | the on-call | only the cells where an error surfaces; a served ask leaves naught to read, so the reader seat has no happy cell by construction |

## state that is void, with reason

- **concurrency / cache state** — void as an axis. each ask holds its own in-memory endpoint list
  for its whole walk; `delForModel` drops only the on-disk cache entry, and a drop is idempotent
  (two concurrent 404s drop it twice, to the same end). an ask mid-walk is never touched by
  another ask's drop; the next ask reads the list live. no cell differs by concurrency.
- **retry-after** — a render variant, not an axis. present or absent, every hop and every verdict
  is the same; only the exhausted refusal's fix line differs: `retry after Ns (openrouter's
  retry-after)` when any hop carried one, else `retry later, or loosen a promise`. both strings
  are clamped by `getOneFloorExhaustedError.test.ts`, and both exhausted cells (c6, c13) render
  through that one function.
- **the last host fault** — a render variant of the same refusal, not an axis. the refusal keeps
  the last host's error as `cause`, shows its reason (`last host fault: …`) when the body holds
  one, and names the request in the fix only after a host 400 (a context limit, say). every
  verdict is the same with or without it. clamped by `getOneFloorExhaustedError.test.ts` (four
  forms, each snapped) and the real-client test `getOneSuppliedCompletion.integration.test.ts`
  [case3] (`cause` status 429)

- **endpoints per provider** — a variant of the admitted hop, not an axis. `name` reads a
  *provider*, and one provider may own several endpoints of the model (`A/fp8`, `A/bf16`). the
  hop drops every admitted endpoint of the named provider in one step, and the trail carries one
  row per endpoint dropped. the verdict is the same hop whether the provider owns one endpoint or
  several; only the count that leaves and the count of rows differ. clamped by admitted `[case8]`
  (snapped), `asEndpointsSplitByProvider.test.ts`, and `asSupplyAttemptsOfFault.test.ts`. it
  is row c16 in the inventory

## invariants (forbidden combinations)

- **I1** — a caller fault (400, unflagged, name absent) never steps or hops, on either path
- **I2** — no loop. the admitted hop strictly shrinks the set; a host-marked fault that names no
  admitted host walks the set at most one send per endpoint; an unmarked fault rethrows in one send
- **I3** — on the floor path, `flag` and `name` never change a host fault's verdict
- **I4** — `left` exists only after a hop; it has no value for served, caller-fault, and
  unrecognized cells. `flag` and `name` have no value for served (no error body); for
  unrecognized they have a value the rethrow does not read
