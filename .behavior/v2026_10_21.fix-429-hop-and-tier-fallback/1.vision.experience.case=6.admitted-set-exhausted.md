# case=6 — admitted set, every host faults

feel: sharp · care: critipath · actors: caller, then on-call who reads the error

## narrative
a bad hour: A throttles (429, retry-after 7), B rejects with a host 400, C is unreachable (404).
each hop drops the faulted host; the third leaves `only` empty. the ask refuses loud with a
`MalfunctionError` the on-call can read in one glance: each host, what it did, and the wait
openrouter asked for. the 404 also dropped the model's cached endpoint list, so the next ask
reads it live. the fix line says when to retry.
