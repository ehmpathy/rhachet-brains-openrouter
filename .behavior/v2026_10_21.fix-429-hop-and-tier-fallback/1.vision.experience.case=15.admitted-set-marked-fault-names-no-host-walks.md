# case=15 — admitted set, a host fault, marked, that names no host

feel: happy (served) · sharp (all walked) · care: critipath · seats: participant, then reader

## narrative
a ci suite asks on `deepseek/flash/speed=min100tps&privacy=full`, no floor; cheap and dear
qualify. openrouter answers `429 Provider returned error` — #21's own message — with the host
marker but no `provider_name`. a host failed, yet openrouter did not say which, so no host can be
dropped from the set. the ask walks the set one host per send, cheapest first, as a floor walk
does: cheap alone throttles again and is stepped past; dear alone serves. the suite gets its
answer; `supply.attempts` reads `[{ cheap, throttled }, { dear, served }]`.

if every host throttles alone too, the walk ends and the ask refuses loud, as c6 does: each host
and its outcome, openrouter's `retry-after`, the last host's reason, and its error as `cause`.

## bdd
```
given  [case15] qualified = [cheap, dear], no floor
when   [t0] the send answers a marked 429 that names no host; cheap alone throttles; dear serves
then   the set is retried by the client, then walked — admits =
       [[cheap, dear] × 3, [cheap] × 3, [dear]]
then   attempts = [{ cheap, throttled }, { dear, served }]

when   [t1] every send answers a marked 429 that names no host
then   a MalfunctionError lists each host as throttled, after one walk of the set
then   it names openrouter's retry-after wait
```
