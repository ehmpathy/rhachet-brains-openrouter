# case=6 — a filtered brain chosen by name from config

**feel** happy · **care** critipath (systems select brains by `choice`, not by `genBrainAtom`)

## narrative

rae's ci config says `--brain openrouter/deepseek/flash/floor&privacy=full`. the package lists
five static brains, and declares patterns to rhachet — one per static slug
(`openrouter/deepseek/flash/*`) and one for any openrouter id (`openrouter/*/*/*`). a pattern is
a claim about where to send a name, never a brain anyone picks.

**before rhachet routes patterns**, the first run fails: `brain not found`, with the available
list — the five static slugs. rae checks the readme, which says a filtered slug is registered one
line at a time until then, and shows that line. rae adds it. the next run picks the brain by the
exact name in the config and serves. the same one line works for an unlisted id
(`openrouter/acme/new-model/floor`).

**after the reseed lands**, rae's config works as written, with no line added: no listed brain
matches the name, a declared pattern does, and rhachet hands the name to us.
