stand up `rhachet-brains-openrouter`: a rhachet brain package that reaches any model on

## the ask

### 1. slugs name an openrouter model, plus optional route filters

the base slug is `openrouter/$theirSlug`, where `$theirSlug` is openrouter's own model id
(e.g. `openrouter/deepseek/deepseek-chat`). after it, an optional filter segment.

both of these forms must parse, and mean what they say:

```
openrouter/$theirSlug/floor&speed.min=50tps
openrouter/$theirSlug/floor&speed=min50tps&region=usa&precision=fp8
```

| filter | sense |
|---|---|
| `floor` | route to the cheapest provider that qualifies |
| `speed.min=50tps` · `speed=min50tps` | only providers at ≥ 50 tokens/sec — two spellings, one sense |
| `region=usa` | only providers that serve from the usa |
| `precision=fp8` | only providers that serve that quantization |

- filters compose with `&`, in any order
- a filter openrouter cannot honor, or a malformed one, fails loud at slug parse with a fix — never
  a silent route to some other provider
- 🔴 **verify each filter against openrouter's provider route api before you build it.** `floor`,
  min-throughput, and quantization look like real route options. **`region` is unverified** — if
  openrouter has no region control, say so in a fulcrum and propose the honest alternative (e.g. an
  allowlist of us-hosted providers). do not fake it
