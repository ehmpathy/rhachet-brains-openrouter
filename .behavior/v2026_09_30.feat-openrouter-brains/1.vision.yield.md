# 1.vision — openrouter brains, with route promises in the slug

## the outcome world

### before

a dev wants deepseek cheap, fast, usa-hosted, and never retained. on fireworks they get one
provider, one price. on raw openrouter they hand-write a `provider: { ... }` object per call, at
the call site, and then **hope**. measured 2026-10-01: the package's own reviewer calls, with no
route preference, went to AtlasCloud and Together — **1.4–4.9× the cheapest healthy host**, and
AtlasCloud is not on openrouter's zero-retention list. nobody chose that. nobody could see it.

### after

```ts
import { genBrainAtom } from 'rhachet-brains-openrouter';

const atom = genBrainAtom({
  slug: 'openrouter/deepseek/flash/floor&speed=min50tps&region=usa&privacy=full',
});
const { output, metrics } = await atom.ask({ role: { briefs }, prompt, schema }, context);
// metrics.route = {
//   provider: 'Fireworks', generationId: 'gen-…', costUsd: 0.0000412,
//   attempts: [{ tag: 'fireworks/us', outcome: 'served' }],
//   choice: { funnel: [{ promise, left }…], ranked: [{ tag, estUsd, tps, verdict }…] },
// }
```

one string says *which model* and *what the caller is owed*. the atom enforces each word before
the call, checks the served provider after it, and a test clamps each promise.

### the aha

> **every word in a slug is a promise the atom enforces, and an answer from a host we did not pin
> is never returned.** `privacy=full` is not a hint to openrouter. it limits the call to
> openrouter's own zero-retention list, and openrouter's native `zdr` filter backs it.

### a day in the life

- 09:00 — a stranger follows the readme: account → credits → key with a weekly limit → keyrack
  → one probe prints `✔ openrouter answered`.
- 10:00 — a reviewer fleet runs on `openrouter/deepseek/flash/floor`. each call lands on the
  cheapest healthy host; when that host throttles, the atom walks to the next cheapest, not to
  openrouter's balancer. the trail is in `metrics.route`.
- 11:00 — compliance asks for usa-only, never retained. one slug edit. the atom refuses to start
  if no endpoint can keep all four promises, and names each endpoint with the promise it fails.
- 14:00 — a new model ships on openrouter at noon. `openrouter/acme/new-model/floor` works at 14:00
  with no release of this package: rhachet sends the unknown name our way, and we look it up.

## the frame — a promise is enforced, checked, and clamped

| stage | what it means | where it lives |
|---|---|---|
| **enforce** | before the call: the qualified endpoint set is computed from live data, and the request can reach no endpoint outside it (`only` + `allow_fallbacks: false`) | the atom |
| **check** | after the call, before the answer returns: the response names the provider that served — it must match the endpoint we pinned, or no answer is returned. no wait, no background work (F14) | the atom |
| **clamp** | a test per promise that goes red if enforce or check is removed — dogfooded red once | the test suite |
| **demonstrate** | one vision case per promise, then one acceptance test per case | `case=*` → `*.acceptance.test.ts` |

a promise that cannot clear all four is **not offered**. it is refused at parse, with why.

⚠️ the check sees a provider name, not an endpoint. so it cannot part two endpoints of one
provider (`fireworks` vs `fireworks/us`). where that matters — `region=usa` — the atom **trusts
the pin** (wisher ruled, F14) and returns the generation id in `metrics.route.generationId`, so a
caller who must audit can read the served `endpoint_id` later at no cost to the ask.

## what we publish

| kind | slugs | who maintains | why |
|---|---|---|---|
| **static** — versionless per tier | the five: `openrouter/deepseek/flash` · `…/deepseek/pro` · `…/moonshotai/pro` · `…/z-ai/pro` · `…/z-ai/flash` (each also as `…/latest`) — wisher ruled, F13 | us, with a live probe per re-aim | a short, durable menu. **we promise long-term support for exactly these names** |
| **static + filters** | `openrouter/deepseek/flash/*` — one filter pattern per static slug | none per combo | any promise set on a supported model |
| **routed patterns** | `openrouter/*/*/*` and `openrouter/*/*` — claims to rhachet, never brains | none | any model openrouter serves, with or without filters, no release owed |

**a routed pattern is not a brain.** no caller picks it, and the registry lists it as a pattern,
not an atom. it says to rhachet: *a choice of shape `openrouter/{author}/{model}[/{filters}]`
that matches no listed brain — send it to us.* we then look the id up in openrouter's catalog:

| the caller names | what happens |
|---|---|
| `openrouter/deepseek/flash/floor` | matches a static slug plus filters |
| `openrouter/acme/new-model/floor` | no listed brain; fits the pattern; we look the model up and build its atom |
| `openrouter/acme/no-such-model/floor` | fits the pattern; openrouter has no such id ⇒ `ConstraintError` before any spend: names the slug, says openrouter has no such model, and recommends the **most similar ids** in openrouter's catalog (cached `/models` read; edit distance on author and model, top 5), each as a ready slug with the caller's filters kept |
| `openrouter/*/*/*` (the literal) | refused: a pattern is not a model |
| `openrouter/acme/new-model` (no filter segment) | fits `openrouter/*/*` ⇒ we look it up and serve it via openrouter's balancer, like a bare static slug (Q25, ruled) |

**rhachet cannot route to a pattern yet**: its choice match is exact
(`genContextBrain.js:79,92,103`). until it can, an unlisted id serves via direct
`genBrainAtom({ slug })`, and the static slugs serve by name. the route is a reseed:
[`dreams/v2026_10_01.reseed.rhachet-wildcard-brain-dispatch.md`](./dreams/v2026_10_01.reseed.rhachet-wildcard-brain-dispatch.md).
when it lands, no release of this package is owed.

### the static slugs map to pins, as today

`openrouter/deepseek/flash` → `openrouter/deepseek/flash/latest` → `deepseek/deepseek-v4.1-flash`
(probed live 2026-10-01). latest / pin / bare stay one shape (`rule.require.versionless-slug-per-tier`).
a pinned slug is openrouter's listed id verbatim: `openrouter/deepseek/deepseek-v4.1-flash/floor`.
an unlisted id takes the same shape for an id outside the config: `openrouter/acme/new-model/floor`.

## the contract

### slug grammar

```
openrouter/{author}/{tier}[/{filters}]        static:   openrouter/deepseek/flash/floor
openrouter/{author}/{model}[/{filters}]       unlisted: openrouter/z-ai/glm-5.3/privacy=full
filters = filter ( '&' filter )*              any order, each key once
```

`{author}` is openrouter's own author segment (`deepseek`, `moonshotai`, `z-ai`), as the extant
`AtomSlug.latest.ts` already uses it. a static `{author}/{tier}` is checked first; else the two
segments are openrouter's id, verbatim. openrouter ids are always two segments, so the fourth
segment is unambiguously the filters.

⚠️ a static slug **shadows** an openrouter id of the same shape. the tier words (`pro`, `flash`)
are not openrouter model names today; a unit test asserts that against a live `/models` read, so
a future collision fails loud instead of misroutes.

### the promises — each word, how it is enforced, how it is proven

| word | the promise | enforce (before) | prove (after) | evidence it can hold |
|---|---|---|---|---|
| `floor` | the cheapest endpoint that keeps every other promise and is healthy now | qualified set sorted cheapest-first; the atom sends one endpoint at a time (`only: [e]`, no fallback) and on a 429 walks to the next (F3) | attempt trail = a prefix of our order; served = first non-throttled | probe 2: openrouter's `sort: price` fell from a 429 to an endpoint 8 places pricier. our walk cannot |
| `speed=min50tps` · `speed.min=50tps` | only endpoints with measured p50 ≥ 50 tok/s, last 30 min | filter the authenticated endpoints read; `null` = unmeasured = excluded | served endpoint ∈ set | authenticated reads return p50 on 32 of 33 endpoints; the 2nd cheapest runs at 7 tok/s |
| `precision=fp8` | only that quantization | endpoints `quantization` filter + native `quantizations` | served ∈ set. **attested** (F18): the provider declares its quantization | native field is hard (docs) |
| `privacy=full` | not retained, not trained on | `only` ⊆ openrouter's `/endpoints/zdr` list for the model; also send `zdr: true` and `data_collection: 'deny'` | served ∈ zdr list, re-read. **attested, not proven** (F18): no client can observe retention; openrouter screens the provider's terms, and recourse for a breach is contractual | probe 1: `zdr: true` held the list; `data_collection: 'deny'` alone served AtlasCloud, **off** the list. so `deny` is not enough |
| `region=usa` | the endpoint that serves sits in the usa | `only` ⊆ endpoints whose **tag** carries a usa region (`fireworks/us`); a base tag never qualifies — a company's domicile is not its datacenter (F1) | **trusted, not proven** (wisher ruled, F14): provider name matches the pin; `metrics.route.generationId` lets a caller audit the served `endpoint_id` later | one such tag for v4.1-flash today; openrouter's in-region api and key-level `allowed_data_regions` are stronger and plan-gated (Q16) |
| `price.max=0.5usd/M` | never billed above this rate | native `max_price` + the qualified set. **no cap without this word** (wisher ruled, F17) | `usage.cost` ≤ tokens × bound | probe 1: an impossible bound → 404 before any spend |
| *(always)* | the caller's schema and tools are honored | `require_parameters: true` | served endpoint lists the parameter | probe 1: relace (no `response_format`) refused with 404 |

### what a bare slug promises — F10

`openrouter/deepseek/flash` with no filters: **openrouter's balancer**, as today (wisher ruled).
the atom sends no `provider` preference and makes no route promise; `metrics.route` still reports
the provider that served. measured: the balancer weighs speed and uptime beside price and cost
1.4–4.9× the floor on 2026-10-01 — so a caller who wants the cheapest host writes `floor`.

### the price range — how a caller lives with 23×

| question | answer |
|---|---|
| what will this ask cost, before? | `spec.cost` is an **estimate**, never a bound. rhachet's `spec` is static ("the static specification the supplier guarantees", `BrainAtom.d.ts:51`) and built synchronously. static slug: the model's typical rate, declared in `BrainAtom.config.ts`. unlisted id: the model's catalog rate, read when the atom is built if rhachet's routed-pattern hook can await (asked in the reseed), else a labelled placeholder (F17) |
| is a price bound enforced? | only when the caller writes `price.max` (wisher ruled, F17): then every ask sends `max_price` and openrouter refuses any endpoint above it, before spend. no default cap |
| what does the qualified set cost? | with `floor`, the walk reads it live; `metrics.route.attempts` lists each endpoint and its rate. a zero-qualified refusal names the cheapest rate on offer (case=4) |
| what did it cost, after? | `metrics.cost.cash` = `usage.cost`, openrouter's charge, per response |
| does the static estimate stay true? | the static catalog probe (`BrainAtom.config.integration.test.ts`) asserts each static estimate sits within the model's live endpoint rate range; drift fails it loud |

### refusals — named, with the fix

| when | refusal |
|---|---|
| parse: unknown key, bad value, unit, duplicate, empty segment, precision outside the enum, region other than `usa`, privacy other than `full` | `ConstraintError`, names the bad word and the valid set (case=3) |
| enforce: zero endpoints keep every promise | `ConstraintError: no endpoint of {model} keeps {promises}` — a table of each endpoint and the promise it fails (case=4) |
| enforce: endpoints read or zdr read fails | `MalfunctionError` — never an unfiltered call (case=11) |
| walk: every qualified endpoint throttles | `MalfunctionError: rate limited`, every attempt listed, `retry-after` if sent (case=14) |
| target: an unlisted id openrouter does not know | `ConstraintError` before any spend — the most similar catalog ids, as ready slugs (case=20) |
| target: a literal pattern (`openrouter/*/*/*`, `openrouter/*/*`) | `ConstraintError` at parse — a pattern is not a model (case=20) |
| check: the response names a provider other than the one pinned | `MalfunctionError: openrouter served {provider}, pinned {endpoint}` — the answer is **withheld** (case=22, F14) |
| account: 402 / 401 | names `/settings/credits` or the keyrack fill (case=7, case=12) |

## requirement combinations — what we must support

six requirement axes a caller can combine: **model** (static · unlisted) × **price** (none ·
floor · price.max) × **speed** × **region** × **privacy** × **output** (text · schema · tools).
the set of qualified endpoints is their intersection, so each added promise can only shrink it.
measured for `deepseek-v4.1-flash`, early 2026-10-01, 33 endpoints. **a snapshot, not a table
this package holds**: openrouter re-serves the endpoints list live, and `floor` re-ranks on every
ask by input rate (F20, ruled: output rates never move the rank). so one slug lands on
different hosts as speeds and rates move, and as the ask's shape (text or schema) changes. rates below
are the **input** rate per 1M tokens.

| combination | qualified | floor lands on | note |
|---|---|---|---|
| bare | 33 | — (openrouter's balancer: AtlasCloud, Together) | no route promise; `floor` alone lands on relace $0.026/M input |
| `speed=min50tps` | 26 | inference-net $0.04/M | |
| `privacy=full` | 27 | relace | the 6 absent include AtlasCloud, today's default pick |
| `privacy=full` + `speed=min50tps` | 21 | inference-net | |
| `precision=fp8` + `speed` + `privacy` | 11 | morph $0.053/M | |
| `privacy` + `speed` + schema output | 21 | inference-net | two endpoints lack `response_format` (relace, one `baseten/fp8`); a json schema drops them |
| `floor` + schema output | 31 | open-inference/fp4 $0.03/M | relace drops; the floor lands on a 7 tok/s endpoint — add `speed` to avoid it |
| `region=usa` | 1 | fireworks/us $0.45/M | **17× the floor** — usa is a price |
| the wish composite: `floor&speed=min50tps&region=usa&privacy=full` | 1 | fireworks/us | throttled 2 of 2 in probe 1 ⇒ a fleet on this slug will see case=14 often |
| `region=usa` + `precision=fp8` | 0 | — | refused, case=4 |

**re-measured live later that day** (the run behind the reviewer slug,
`floor&speed=min50tps&privacy=full`): relace had risen from 47 to 71 tok/s. a short json-schema ask
landed on dekallm (relace out: no `response_format`); a 22k-token **text** ask landed on **relace**,
since a `z.string()` reply needs no `response_format` (F21). the funnel is in `metrics.route.choice`.

⇒ three things the matrix makes plain:
1. **promises compose by intersection.** no combination needs special code; the risk is only an
   empty or one-endpoint set, and both are named loud.
2. **a one-endpoint set is fragile.** no walk exists, so throttle = failure. the refusal at
   ask time says so, and the readme sets the expectation for `region=usa`.
3. **the price of each promise is visible before spend.** `spec.cost` is a static estimate
   (F17), so it cannot show what `region=usa` costs. a `price.max` below the qualified set does:
   the ask refuses before spend and the funnel names the one usa endpoint and its rate (case=5,
   case=4).

## mental model

**to a friend:** "openrouter sells one model from thirty hosts at thirty prices. the slug says
which hosts you'll accept — cheapest, fast, us, private — and the package pins one of them per
call, and refuses any answer from a host it did not pin."

| they say | we say |
|---|---|
| "cheapest host" | `floor` |
| "fast hosts only" | `speed=min50tps` |
| "quant" | `precision` |
| "us only" | `region=usa` |
| "zero retention", "no train" | `privacy=full` |
| "budget cap" | `price.max` |
| "host", "provider" | endpoint (a provider × a deployment tag) |

## evaluation

| goal | met? |
|---|---|
| any openrouter model, no per-model upkeep | ✔ the routed pattern; by name once rhachet routes patterns (reseed); an unknown id names its nearest catalog matches |
| a short list we support long-term | ✔ the five static per-tier slugs (F13, ruled) |
| both filter forms parse, mean what they say | ✔ |
| bad filter fails loud at parse, with fix | ✔ |
| never a silent route elsewhere | ✔ when filtered: enforced (`only`, no fallback, our walk) and checked (response `provider` vs the pin, before return). bare: openrouter's balancer, by choice |
| region honored | ◐ the pin is enforced; the endpoint within one provider is **trusted**, auditable via `generationId` (F14, ruled); narrow by design (F1) |
| privacy honored | ◐ the pin to a zdr-listed endpoint is enforced (`only` + native `zdr: true`) and checked; that the host keeps no data is **attested** by the host and screened by openrouter, never observable by a client (F18) |
| price range handled | ✔ `price.max` when the caller wants a bound (F17, ruled); true cost per response |
| zero fireworks identity | ✔ case=8 clamp |

### latency — the do-it-ourselves route, measured (Q18)

live spike, 2026-10-01, `deepseek-v4.1-flash` ([evidence](./appendix/research.latency-spike.v2026_10_01.json)):

| piece | p50 | cold / max | note |
|---|---|---|---|
| endpoints read | 46ms | 290ms | 46KB per model |
| zdr list read | 143ms | 249ms | **1.17MB**, all models |
| ask, openrouter's balancer (today) | **1822ms** | 2056ms | |
| ask, pinned to one endpoint (`only: [e]`, no fallback) | **426ms** | 924ms | inference-net; the gap to the row above is the host, not the pin |
| one walk hop, openrouter-side refusal (n=3) | 42ms | 93ms | a 429 from the upstream host was **not** measured — it costs at least a round trip to that host; the integration test records it |
| generation record, after the answer | **10.7s** | 16.6s | too slow to block any answer on; no ask waits for it — its id rides in `metrics` for a later audit (F14) |

⇒ the route we own **adds no latency of its own**: a pinned call costs what its endpoint costs.
here the pinned endpoint (inference-net) answered ~1.4s faster than the endpoints the balancer
chose (AtlasCloud, Together) — that gap is the hosts, not the pin, and a cheaper pinned host can
be slower (open-inference, 7 tok/s). the reads cost ~190ms cold, ~0 warm (F16).

⇒ the check is one grain, and it blocks without a wait (F14):
- **every filtered ask, free:** each call pins one endpoint with no fallback, so openrouter can
  serve no other. the response's own `provider` field must name that endpoint's provider —
  checked before the answer returns. `precision` and `privacy` also carry a native filter
  (`quantizations`, `zdr`) as a second, independent enforcement.
- **`region=usa` is trusted at endpoint grain.** the provider name cannot part `fireworks` from
  `fireworks/us`, and only the generation record (~11s later) can. the wisher ruled the wait not
  worth it. so the atom returns at once and puts the generation id in `metrics`; an auditor reads
  the served `endpoint_id` later.
- **no background work, ever.** a short-lived cli exits before the record lands, so a background
  audit would run only sometimes.

### the reads are memoized on disk — F16

memory, then disk, under `$HOME/.rhachet/storage/repo=openrouter/role=any/cache/`, ttl 30 min —
the same window as openrouter's throughput stat (F19: in-house, an atomic temp-file + rename, no
new dep; `withSimpleCacheAsync` stays the alternative, Q19). once a read lands on disk, every
process on the machine reuses it for the half hour. asks in flight in one process share one read
via the in-memory promise map; a failed read is never cached. processes that
start cold at the same instant may each read once (46ms, 46KB each); that is the worst case, and
it is cheap. a corrupt cache file reads as a miss — one live read, never a stuck failure
(`asCacheEntry`). owed in execution, not built: a cached endpoint that openrouter then refuses as
absent should drop its model's entry and re-read once (case=21 `[t2]`); today a stale entry
lives out its 30 minutes.

**cons:** worst-case staleness 60 min for throughput (a 30-min window, cached 30 min);
`region=usa` is narrow, throttles, and is trusted rather than proven at endpoint grain.

## what is awkward

- **`region=usa` is the one promise we trust rather than check at endpoint grain.**
  `fireworks` and `fireworks/us` share a provider name; only the generation record parts them,
  ~11s late (F14). the audit id in `metrics` is the escape hatch; Q16 could remove the gap.
- **`region=usa` is honest and narrow.** one endpoint for v4.1-flash, at 17× the floor. a caller
  who expected a list of us hosts will meet a refusal or a throttle.
- **a bare slug keeps openrouter's pricier pick** (F10, ruled). the cheap host is one word away
  (`floor`), but the default does not take it.
- **unlisted ids wait on rhachet** to route a pattern; until then, one line registers each.
