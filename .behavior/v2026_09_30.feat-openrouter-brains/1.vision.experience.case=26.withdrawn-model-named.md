# case=26 — a withdrawn model is refused by name, with live ids offered

**feel** sharp · **care** critipath (rare, yet it hits every caller of that slug at once; a bare
404 sends each one to search for a replacement by hand)

## narrative

kai's ci asks `openrouter/qwen/qwen3-max/floor`. openrouter dated that model for withdrawal on
2026-10-09, and the date has passed. the atom reads the date from openrouter's own
`expiration_date` (F23) before any spend. the ask fails with a `ConstraintError`, which names the
date and lists undated ids as ready slugs, filters kept. kai swaps one id and ships.

a 404 that arrives mid-ask, from a model withdrawn since the catalog was cached, routes into the
same named error.

a tier alias never names a dated model. the liveness suite fails the day openrouter dates one,
weeks before the date lands, and the fix is one re-aim in `PINNED_BY_LATEST_SLUG`.

## [tn] sketch

```
given('[case26] a model whose withdrawal date has passed')
  when('[t0] kai asks it')
    then('ConstraintError names the date; no call was sent')
    then('undated ids are offered as ready slugs, the filter kept; a dated id is never offered')
given('[case26] a 404 from openrouter mid-ask')
  when('[t1] the ask fails')
    then('it is the same named withdrawal error, not a bare NotFoundError')
given('[case26] a tier alias')
  when('[t2] openrouter dates the model it names')
    then('BrainAtom.config.integration [case3] goes red before the date lands')
```
