# case=3 — bad filter refused at parse

**feel** sharp · **care** critipath (typos are frequent; a silent typo bills a wrong route, and a
typo in `privacy` or `region` would void a promise the caller believes they hold)

## narrative

lee types `openrouter/deepseek/flash/precision=fp9&speed.min=fast&privacy=ful`. `genBrainAtom`
throws before any network call. the error names all three faults, each beside its valid forms.
lee fixes them in one edit. no read was made, no cent was spent.

## [tn] sketch

```
given('[case3] a slug with malformed filters')
  when('[t0] lee types precision=fp9')
    then('ConstraintError: precision fp9 is not a known quantization; lists the valid set')
  when('[t1] lee types speed.min=fast')
    then('ConstraintError: speed.min wants a number + tps, e.g. speed.min=50tps or speed=min50tps')
  when('[t2] lee types privacy=ful')
    then('ConstraintError: privacy accepts only full (no retention, no train)')
  when('[t3] lee types region=us or region=europe')
    then('ConstraintError: region accepts only usa today; names the open question for others')
  when('[t4] lee types price.max=cheap or price.max=-1')
    then('ConstraintError: price.max wants usd per million prompt tokens, e.g. price.max=0.30')
  when('[t5] lee types color=red')
    then('ConstraintError: unknown filter color; lists the known keys')
  when('[t6] lee types speed.min=50tps&speed=min60tps')
    then('ConstraintError: filter speed given twice, in two forms')
  when('[t7] lee types floor&floor')
    then('ConstraintError: filter floor given twice')
  when('[t8] lee types three faults in one slug')
    then('one ConstraintError lists all three, not only the first')
  when('[t9] lee runs any of the above')
    then('no http request was made')
```

## proof & clamp

| promise | proven by | clamp — goes red when |
|---|---|---|
| each malformed filter refused | data-driven unit test over a caselist of bad slugs; each asserts the error class and that the message names the key and its valid forms | a filter key gains a lax parse (e.g. `privacy` accepts aught) |
| refusal precedes spend | unit test injects a fetch spy into the atom's context; asserts zero calls | parse moves after the endpoints read |
| two forms, one sense | unit test: `speed.min=50tps` and `speed=min50tps` parse to equal filter objects; both together refuse | either form is dropped, or duplicates slip through |
