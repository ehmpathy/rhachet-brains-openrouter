# case=20 — any openrouter model, no release of this package

**feel** happy · **care** critipath (the wisher's rule: "eliminate the need for constant updates")

## narrative

at noon openrouter lists a new model, `acme/new-model`. at two, jo wants it behind the reviewer
fleet. jo writes `openrouter/acme/new-model/floor&privacy=full`. it is none of the five static
slugs, but it fits a shape this package declares to rhachet (`openrouter/*/*/*`, or
`openrouter/*/*` with no filters), so
rhachet sends it our way. the atom looks the id up in openrouter's catalog, finds it, and
answers — no issue filed against this package, no release awaited. `spec.cost` is the model's
catalog rate where rhachet's hook lets us read it, else a labelled estimate; the real charge
lands in `metrics` after the ask.

jo then types `openrouter/acme/new-modle/floor`, a typo. the ask refuses before any spend:
openrouter has no such model, and the error lists the closest ids in its catalog —
`acme/new-model` first — each as a ready slug with jo's `floor` kept.

jo tries `openrouter/*/*/*` itself, out of curiosity. refused at parse: a pattern is not a model.

## [tn] sketch

```
given('[case20] a model this package has never heard of')
  when('[t0] jo builds genBrainAtom({ slug: openrouter/acme/new-model/floor&privacy=full })')
    then('the slug parses: id = acme/new-model, filters = { floor, privacy: full }')
  when('[t1] jo asks')
    then('the id is found in the cached /models catalog')
    then('it reads the model endpoints, qualifies, pins, and serves')
    then('no max_price is sent, since jo wrote no price.max (F17)')
  when('[t2] jo asks on a typo id: openrouter/acme/new-modle/floor')
    then('ConstraintError before spend: openrouter has no model acme/new-modle')
    then('the error lists the 5 most similar catalog ids as slugs, filters kept: openrouter/acme/new-model/floor first')
  when('[t2b] jo asks openrouter/acme/new-model, no filters')
    then('the id is found in the catalog; the ask goes via openrouter's balancer, no route promise')
  when('[t3] jo names openrouter/*/*/* (or openrouter/*/*) as the slug')
    then('ConstraintError at parse: a pattern is not a model; names the shape to fill')
  when('[t4] rhachet can route patterns, and jo names the slug as a choice')
    then('no listed brain matches; the declared pattern openrouter/*/*/* does; rhachet hands it to us')
    then('atom.slug = the slug jo wrote')
```

## proof & clamp
