# case=1 — stranger to first call

**feel** happy · **care** critipath (every adopter walks it once; a stall here loses them)

## narrative

dana has never used openrouter. she opens the readme. step one: sign up at openrouter.ai.
step two: `/settings/credits`, add $10, and turn auto top-up **off** so a runaway loop cannot
drain her card. step three: `/settings/keys`, mint a key named `rhachet-dev`, credit limit $5,
reset weekly. the readme tells her why: a key with no limit can spend the whole balance.

step four: she puts the key in the keyrack, then runs the one probe the readme gives. it
answers with a model name, a provider, and a cost of a fraction of a cent. done in ten minutes.

later the readme shows her rotation: mint a new key, swap it into the keyrack, re-run the
probe, then delete the old key.
