# case=5 — the wish composite, every promise enforced

**feel** sharp · **care** critipath (a compliance-minded caller trusts four words at once; one
silent miss and the slug lied)

## narrative

sam's compliance review needs inference that is cheap, fast, usa-hosted, and never retained. sam
writes `openrouter/deepseek/flash/floor&speed=min50tps&region=usa&privacy=full`. sam had assumed
"floor" meant pennies, and caps it: `&price.max=0.10usd/M`. the first ask is refused before a cent
moves — the funnel shows one endpoint keeps the four words, `fireworks/us` at $0.45/M, 17× the
floor. sam raises the cap to `0.50usd/M` with eyes open.

the ask returns at the endpoint's own speed. `metrics.route` shows one attempt: `fireworks/us`,
status 200, the provider it checked, and a `generationId`. the readme tells sam plainly that
`region=usa` is enforced by the pin and **trusted** within the provider: openrouter's response
names `Fireworks`, not which Fireworks endpoint. sam's auditor, once a quarter, feeds the
recorded generation ids to openrouter's `/generation` api and confirms each `endpoint_id` is the
usa one.

later that day sam's fleet runs ten of these at once. some throttle — a one-endpoint set has no
walk — and each throttled ask fails loud with the endpoint named and `retry-after`, never a quiet
reroute to a cheaper host outside the usa.

sam tries `region=usa&precision=fp8` for a second project. refused before any call: a table lists
each endpoint and the promise it fails; none is usa-tagged and fp8.

## [tn] sketch

```
given('[case5] the wish composite: floor&speed=min50tps&region=usa&privacy=full')
  when('[t0] sam builds the atom')
    then('filters = { floor, speed.min: 50, region: usa, privacy: full }')
    then('spec.cost = the static estimate for deepseek/flash — no read')
  when('[t0b] sam asks with price.max=0.10usd/M, below the one qualified endpoint')
    then('ConstraintError before spend; the funnel names fireworks/us and its $0.45/M rate')
  when('[t1] sam asks')
    then('the qualified set = usa-tagged ∩ zdr list ∩ p50 ≥ 50, cheapest first')
    then('the request pins one endpoint: only: [fireworks/us], allow_fallbacks: false, zdr: true, data_collection: deny, max_price = price.max')
    then('response.provider = Fireworks, else the answer is withheld (case=22)')
  when('[t2] sam receives the answer')
    then('it returns with no wait for the generation record')
    then('metrics.route = { provider: Fireworks, generationId, costUsd, attempts: [{ tag: fireworks/us, outcome: served }], choice: { funnel, ranked } }')
  when('[t3] sam asks while the one qualified endpoint throttles')
    then('MalfunctionError: rate limited; names fireworks/us and retry-after; no other endpoint tried')
  when('[t4] sam writes region=usa&precision=fp8')
    then('ConstraintError: no endpoint keeps { region: usa, precision: fp8 }, with the per-endpoint table')
  when('[t5] sam writes region=eu or privacy=some')
    then('ConstraintError at parse: known region usa; known privacy full')
  when('[t6] sam writes the wish's form 2 verbatim: floor&speed=min50tps&region=usa&precision=fp8')
    then('it parses: { floor, speed.min: 50, region: usa, precision: fp8 }, the same as the canonical speed.min form')
    then('on deepseek-v4.1-flash it is refused before spend: the funnel keeps fp8 endpoints at speed>=50tps, then region=usa leaves 0')
    then('the one usa-tagged endpoint, fireworks/us, lists quantization "unknown" (live read, 2026-10-01) — so it cannot keep precision=fp8')
    then('the refusal names the step that hit 0 and says: drop or loosen that promise')
```

the wish's form 1 (`floor&speed.min=50tps`) is case=2's canonical form. form 2 composes by
intersection — each word is one check in the funnel, in a fixed order — so on a model whose usa
endpoint declares fp8, `[t6]` pins it as `[t1]` does; on this model the honest outcome is the
refusal.

## proof & clamp

| promise | proven by (acceptance, live) | clamp — goes red when |
|---|---|---|
| region (enforced) | `[t1]` asserts the pinned tag carries `/us` and is the only tag sent | the qualifier admits a base tag |
| region (auditable) | `[t2]` asserts `metrics.route.generationId` is present, and `metrics.route.provider` is the provider that served. the `endpoint_id` audit is the caller's own `/generation` read (F14 — no test waits on that record) | the id is dropped from metrics |
| no wait | `[t2]` asserts the ask resolves with no generation read in flight (fetch spy) | a hold on the record is re-added |
| privacy | `[t1]` asserts every qualified tag ∈ live `/endpoints/zdr` for the model | the zdr intersection is dropped, or only `data_collection: deny` is sent |
| speed | `[t1]` asserts the pinned endpoint's p50 ≥ 50 in the same read | `null` p50 admitted, or the bar compared wrongly |
| floor | `[t1]` asserts the pinned endpoint is first in the cheapest-first order | the order is not by price |
| no reroute | `[t3]` asserts the attempt list holds exactly one endpoint | `allow_fallbacks` flips to true |

each clamp is dogfooded red once: remove the guard, watch it fail, restore it.
