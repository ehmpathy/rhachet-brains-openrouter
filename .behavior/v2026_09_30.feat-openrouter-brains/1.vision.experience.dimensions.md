# 1.vision.experience.dimensions

two experience spaces, decomposed apart. an **ask** space — someone sends a prompt through an
openrouter atom. a **maintenance** space — someone changes the package. they share no axis, so
one product over both would fill half its cells with "not applicable". each space below has its
own axes and its own walk.

## space 1 — the ask

### the axes

| # | axis | positions |
|---|---|---|
| A | actor | `stranger` (first ask, new account) · `consumer` (a dev, at a keyboard) · `system` (unattended: ci, cron, a reviewer fleet) |
| M | model selector | `static` (a per-tier slug we support long-term: `openrouter/deepseek/flash`) · `unlisted` (any other openrouter id, verbatim — reaches us via the declared patterns `openrouter/*/*/*` and `openrouter/*/*`) |
| B | promise set | `none` (bare: openrouter's balancer, no route promise, F10 ruled) · `measured` (any of `floor`, `speed`, `precision`, `privacy`, `price.max` — each enforced by a pin to the endpoints that qualify on a live list or metric. the grade of each source differs: price is proven by the bill, speed is measured by openrouter, precision and privacy are attested by the provider — F18. the feel is one: a pinned, checked route) · `region` (`region=usa`, with or without others — narrow; the pin is enforced, the endpoint within one provider is trusted, F14 ruled) |
| C | failure point | `none` · `target-unknown` (no such static slug, or openrouter knows no such id) · `parse` · `credential-absent` · `endpoints-read` · `zero-qualified` · `param-unsupported` · `key-limit (402)` · `rate-limit (429)` (every qualified endpoint throttled) · `proof-broken` (the served endpoint is not the pinned one) · `reply-defect` (a 200 whose reply is unusable: failed mid-reply, an error body, empty or prose where json is owed, cut at the output limit, or tool arguments that are not json) · `target-withdrawn` (openrouter dated the model, and the date has passed) · `key-invalid (401)` (a key was supplied, and openrouter rejects it) |
| D | concurrency | `single` · `concurrent` (many asks share one key and one disk cache) · `retried` (the same ask, again, after a failure) |
| E | selection path | `direct` (`genBrainAtom`) · `choice-exact` (rhachet registry, exact slug) · `choice-pattern` (rhachet matches a pattern atom — owed upstream, the reseed) |
| F | ask shape | `text` (a `z.string()` reply: no param sent, none required — F21) · `schema` (an object reply: `response_format` sent and required) · `tools` (tools sent and required) |

### why these are orthogonal

- **M is new and independent of B.** any promise set applies to any model; a static slug only
  fixes which id the atom reads endpoints for.
- **B holds how a promise is kept, which is what the caller feels.** `none` reads no endpoints
  and promises no route — openrouter picks; `measured` checks each word against a list or
  metric; `region` narrows to one or two endpoints and is trusted within the pinned provider.
  three distinct feels.
- **C asks only where the ask stopped.** `proof-broken`: the call returned from a provider other
  than the pinned one, and the atom refused to pass it on. a bare ask pins no endpoint, so it
  cannot meet this C.
- **D is independent of all others. E is independent save for two nature-voids** (below):
  `choice-exact` meets no `parse` failure, and a bare static slug under a choice is always
  `choice-exact`. each void spans a set of cells, but none a whole row or column, so no latent
  axis hides. E gains `choice-pattern`.
- **F is independent of the slug.** the same slug serves a text ask and a schema ask; F is a
  property of the ask, not the model or the promise words. it changes the experience: a schema or
  tools ask adds a `supports(...)` step to the funnel, so it can meet a host a text ask never
  meets (relace, cheapest for a long text ask, lacks `response_format`), and only it can meet C =
  `param-unsupported`.

### the cells that cannot occur — individual, each by nature

| cell | why it is void |
|---|---|
| E = `choice-exact` × C = `parse` | rhachet matches the choice before any parse; a choice it cannot match is C = `target-unknown` |
| E = `choice-pattern` × M = `static` × B = `none` | exact beats pattern, so a bare static slug is always `choice-exact` |
| F = `text` × C = `param-unsupported` | a text ask sends no param and requires none (F21), so no host can refuse it for one |
| B = `none` × C ∈ {`zero-qualified`, `proof-broken`, `endpoints-read`} | a bare ask reads no endpoints, pins none, and lets openrouter pick (F10) — so it has no qualified set to empty, no pin to break, and no read to fail |

no whole row or column is void, so no further latent axis hides under these.

### the walk

3 × 2 × 3 × 13 × 3 × 3 × 3 positions for A·M·B·C·D·E·F = 6318 tuples. an inventory tuple that
names six positions leaves F collapsed, per its row below. "every non-void cell" in a row
below excludes the voids above — so the `endpoints-read`, `zero-qualified`, and `proof-broken`
rows hold B ≠ `none` only. the walk is by **failure
point**: for each value of C, the table states which axes the outcome reads, and assigns every
non-void cell of that C to exactly one inventory case. an axis absent from "reads" is collapsed,
and the reason says why.

one collapse holds across the whole space, and is stated once:

- **A = `stranger` ≡ `consumer` for the ask itself.** a stranger differs only in the steps
  before the first ask, demoed in case=1, and in one outcome only a new account can meet: an
  empty balance (C = `key-limit`, below).

| C | reads | cells → case | why the collapsed axes do not matter |
|---|---|---|---|
| `none` | M, B, D, E, F | M = `static` · B = `measured` · E = `direct` · D = `single` · F ∈ {`schema`, `tools`} → **13** (`[t0]`: the funnel gains a `supports(...)` step, so the pin is the cheapest endpoint that honors the param) · every other cell below holds any F, and a text ask on case=2's cell is case=2 itself (`[t4]`, and case=13 `[t3]` shows the contrast) · M = `static` · B = `none` · E = `direct` · any D → **1** · M = `static` · B = `none` · E = `choice-exact` · any D → **10** · M = `unlisted` · any B · E = `direct` · any D → **20** (F ∈ {`schema`, `tools`} on its single measured ask → **13**: the `supports(...)` step reads the endpoints list, not the model id, so 13's demo on a static slug holds for an unlisted one) · M = `static` · B = `measured` · E = `direct` · D = `single` · F = `text` → **2** · … D = `concurrent` → **21** · … D = `retried` → **16** · M = `static` · B = `region` · E = `direct` · any D → **5** · any M · B ≠ `none` · E ∈ {`choice-exact`, `choice-pattern`} · any D → **6** (for M = `unlisted`, `choice-exact` = an unlisted id registered by hand, case=6 `[t1]`; `choice-pattern` = a declared `openrouter/*/*/*` or `openrouter/*/*`, case=6 `[t2]`; M = `unlisted` · B = `none` under choice → **6** too) | A is collapsed. F is read only for the single direct measured ask — the one cell where the extra `supports(...)` step changes which host serves; under a bare slug the balancer decides with or without it (a bare ask that needs a param sends `require_parameters`), under `region` the set is one or two endpoints either way, and under concurrency, retry, or a choice the param step is the same step as in the single direct ask. under a choice the registry step is the experience; once matched the ask runs as its direct twin. `region` holds one endpoint or two, so a race or a retry meets the same pinned call (case=5 `[t3]`). the price promise is demoed apart in **23**, which shares case=2's cells: each promise word owes its own proof (the frame), not its own cell |
| `target-unknown` | M, E | M = `static` · E = `direct` → **19** · M = `unlisted` · E = `direct` → **20** (`[t2]`) · E ∈ choice → **6** | a static typo is refused by the slug map before any call; an unlisted id openrouter lacks is refused from the cached catalog before any spend, with the nearest ids suggested; a choice is refused by the registry. actor, promise set, and concurrency are invisible |
| `parse` | F | a malformed tool execution handed back, F = `tools` → **28** · every other non-void cell → **3** (the literal `openrouter/*/*/*` lands here too, case=20 `[t3]`) | refused before any network call; no state is shared |
| `credential-absent` | — | every non-void cell → **12** | refused before any network call |
| `endpoints-read` | — | every non-void cell → **11** | every filtered ask reads (cached); a failed read caches no set, so concurrent asks fail alike; a retry that serves is C = `none`, D = `retried` (case 16) |
| `zero-qualified` | — | every non-void cell → **4** (case=5 `[t4]` meets the same refusal from the wish composite) | the funnel is one experience whatever the promise words: a set emptied, and the step that emptied it named. the set is a property of the model and the promises, not of who asks or how. |
| `param-unsupported` | F | F ∈ {`schema`, `tools`} → **13** (F = `text` is void) | openrouter refuses per request, whatever the slug or path; only an ask that sends a param can be refused for it |
| `key-limit (402)` | A | A = `stranger` → **17** · A ∈ {`consumer`, `system`} → **7** | openrouter answers per key |
| `rate-limit (429)` | B, D | B = `none` → **24** · B = `region` → **5** (`[t3]`) · B = `measured` · D = `single` → **18** · B = `measured` · D ∈ {`concurrent`, `retried`} → **14** | for a filtered ask this C is the walk exhausted — a walk absorbs most throttles (case=21); a one-endpoint `region` set has no walk, so it meets this C first. a bare ask has no walk of ours: openrouter's balancer falls back on its own, and a 429 means it ran out — a distinct feel, with no attempt trail |
| `proof-broken` | — | every non-void cell → **22** (a reply that names no provider lands here too, `[t2]`: the pin cannot be proven) | the pinned call came back from elsewhere, or from a host the reply does not name; who asked, which slug, and how often are invisible to the refusal |
| `key-invalid (401)` | — | every non-void cell → **29** | openrouter rejects the key itself, whoever asks and however; the fix is a new key |
| `reply-defect` | B, F | F = `tools` with tool arguments that are not json → **27** · every other non-void cell → **25** (B = `measured` with `floor`: the walk steps one hop first, `[t0]`; any other B: the named error at once, `[t1]`–`[t2]`) | the reply is read the same way whoever asked and however often; only whether a walk can step past it, and whether a tool call carried it, change what the caller sees |
| `target-withdrawn` | — | every non-void cell → **26** | the date is read from the cached catalog before any spend; a mid-ask 404 routes to the same error. who asks, with which promises, is invisible to the refusal |

a caller's own tool loop can hand back an execution that breaks its type's promise (an error
signal with no error in its output). it is refused before the continuation is sent, so it sits
under C = `parse`, F = `tools` → **28**, an alterpath beside case=3.

the inventory rows are these cases, each written with one representative tuple and its
"same for" set, which cites this table.

## space 2 — maintenance

### the axes

| # | axis | positions |
|---|---|---|
| M1 | task | `identity-swap` (fireworks → openrouter) · `model-add` (a static slug, or a re-aim) · `brief-rewrite` (repo-local rules) |
| M2 | outcome | `clean` · `stray-left` (a missed name, or an unprobed id) |

### why these are orthogonal

- **M2 does not depend on M1.** any task can finish clean or leave a stray.
- **M1 does not depend on M2.** the outcome is judged after the task, so it cannot pick the task.

M1 × M2 = 6 cells, none void. the `stray-left` cells are the sharp ones; each is caught by a clamp.
