# case=11 — a read the promises need fails

**feel** sharp · **care** critipath (rare, but its wrong answer — a silent unpinned route — is
unrecoverable: the caller would believe they got fp8 / ≥ 50 tps / zero retention and never learn
otherwise)

## narrative

mo runs `openrouter/deepseek/flash/privacy=full` while openrouter's endpoints api answers 503.
if a read from the last 30 minutes sits in the disk cache, mo never notices — the walk uses it.
if not, mo sees one error, at once: the endpoints read failed, so no promise could be checked;
a retry is safe. no answer comes back from some host mo never chose. the same holds when the
zdr list read fails under `privacy=full`.

## [tn] sketch

```
given('[case11] a filtered slug, and a read the filters need fails')
  when('[t0] mo asks; the endpoints read fails; no cache entry')
    then('a malfunction error: "openrouter read failed: GET /models/…/endpoints → 503. no promise could be checked, so no call was sent. a retry is safe."')
    then('its class is MalfunctionError once helpful-errors is upgraded past 1.5.3, which lacks it; a HelpfulError until then')
    then('the error carries the http status')
    then('no chat completion request was sent')
  when('[t1] mo asks privacy=full; the zdr list read fails; no cache entry')
    then('MalfunctionError names the zdr read, not the endpoints read')
    then('no chat completion request was sent')
  when('[t2] mo asks; the endpoints read fails; a cache entry < 30m old exists')
    then('the walk uses the cached set and the ask serves')
  when('[t3] mo retries once the api is back')
    then('the ask serves from a qualified, pinned endpoint')
  when('[t4] mo asks on a bare slug while the endpoints api is down (a contrast; cell B=none·C=none)')
    then('the ask serves via openrouter's balancer — a bare slug reads no endpoints (F10), so the outage cannot reach it')
```

## proof & clamp

| promise | proven by | clamp — goes red when |
|---|---|---|
| a failed read → no ask | unit test with an injected fetch that fails the read; asserts the error class and zero chat calls | a catch is added that falls back to an unpinned ask |
| the right read is named | caselist unit test: endpoints-fail vs zdr-fail messages differ | the two reads share one generic message |
| a warm cache rides out an outage | integration test seeds the disk cache, then fails the read; asserts a served answer | the cache wrap is removed or bypassed on error |
