# case=23 — the cost is estimated before the ask, bounded on request, and true after

**feel** happy · **care** critipath (one model spans 23× on prompt rate across its endpoints; a
budget that cannot see that range is a guess)

## narrative

priya budgets a nightly batch on `openrouter/deepseek/flash`. before the run she reads
`atom.spec.cost`: the model's typical rate, declared in config — an estimate, and the readme says
so. no bound applies yet: a bare slug goes through openrouter's balancer, which may pick a host
several times the floor. priya wants a hard cap, so she adds `price.max=0.2usd/M`. now every
ask sends `max_price`, and openrouter refuses any endpoint above it before any spend.
`metrics.cost` shows what each ask actually paid.

she tries `price.max=0.001usd/M` by mistake and is refused at ask time, with the cheapest rate
on offer named, before a cent moves.

## [tn] sketch

```
given('[case23] a static slug with a 23× spread of endpoint rates')
  when('[t0] priya reads spec.cost')
    then('spec.cost = the static estimate for the slug, labelled an estimate')
    then('it was computed with no network read')
  when('[t0b] priya asks with no price.max')
    then('no max_price is sent; no bound applies (F17)')
  when('[t1] priya adds price.max=0.2usd/M')
    then('every ask sends max_price = 0.2usd/M')
  when('[t2] priya asks')
    then('metrics.cost.cash = usage.cost from the response')
    then('usage.cost ≤ tokens × the bound')
  when('[t3] priya sets a bound below every endpoint')
    then('ConstraintError: no endpoint at or below {bound}; cheapest is {rate} at {endpoint}')
```

## proof & clamp

| promise | proven by | clamp — goes red when |
|---|---|---|
| estimate, synchronous | unit test on the spec transformer with a fetch spy at zero calls | the spec reads the network |
| no default bound | unit test: a slug with no `price.max` sends no `max_price` | a default cap is added |
| static estimate stays near true | the static catalog integration probe asserts each estimate lies within its model's live endpoint rate range | the estimate drifts out of range |
| bound enforced | acceptance asks with `price.max` set; asserts `usage.cost ≤ tokens × bound` | `max_price` is dropped from the request |
| impossible bound refused, no spend | acceptance asks with an impossible bound; asserts the error and that `/key` usage did not move | the qualifier lets it through to openrouter |
