# case=2 — filters route the call

**feel** happy · **care** critipath (the reason this package exists)

## narrative

omar runs a reviewer fleet. he wants deepseek cheap, but not on a crawl host, and only fp8.
he writes `openrouter/deepseek/flash/floor&speed.min=50tps&precision=fp8` into his config. a
teammate writes `.../precision=fp8&speed=min50tps&floor` — other order, other form — and the two
of them get the same route, so neither has to learn the other's form. omar checks one response:
`metrics.route` names the endpoint, which is fp8, ran above 50 tok/s in the last 30 minutes, and
was the cheapest such endpoint **for that ask**. the cost on his metrics is openrouter's own
`usage.cost` for that ask (whether it equals the bill to the cent is Q5, settled by a `/key` usage
test).

omar sees a cheaper host on openrouter's model page and asks why it lost. he does not guess:
`metrics.route.choice` lists every endpoint ranked up to the winner, each with its estimated cost
for this ask and a verdict — `qualified`, or the first promise it failed (`speed>=50tps`,
`supports(response_format)`). the funnel beside it says how many endpoints each promise left.

the table under the slug is openrouter's, and it moves. the same slug picked dekallm for a short
json ask and relace for a 22k-token text ask on 2026-10-01 — the rank is by what each ask would
cost, so input-heavy reviews favor a cheap input rate.

## [tn] sketch

```
given('[case2] a static slug and three filters')
  when('[t0] omar writes the canonical form')
    then('filters = { floor, speed.min: 50, precision: fp8 }')
  when('[t1] his teammate writes the alternate form, other order')
    then('filters equal [t0] exactly')
  when('[t2] omar asks')
    then('it reads the model endpoints (disk cache, ttl 30m)')
    then('the qualified set = fp8 ∩ p50 ≥ 50, ranked by input rate, ties to the higher p50 (F20, F3)')
    then('the request pins the first: only: [e], allow_fallbacks: false, quantizations: [fp8]; no max_price, since no price.max (F17)')
    then('response.provider matches e, else withheld (case=22)')
    then('metrics.cost.cash equals usage.cost from the response')
  when('[t3] omar reads why a cheaper host lost')
    then('metrics.route.choice.funnel lists each promise and the endpoints it left')
    then('metrics.route.choice.ranked lists each endpoint up to the winner, plus three past it as the margin, with estUsd and a verdict')
    then('every endpoint ranked above the winner carries the promise it failed, never "qualified"')
  when('[t4] omar asks the same slug with a different ask shape (long text vs short json)')
    then('the rank is recomputed from the live list and the new estimate; the winner may differ')
```

## proof & clamp

| promise | proven by | clamp — goes red when |
|---|---|---|
| two forms, one sense | unit test on the slug parser, data-driven over both forms and every order | a form is dropped or parsed apart |
| the served endpoint keeps all three | acceptance: asserts the pinned endpoint's quantization and p50 from the same read, and that it heads the price order | any filter is skipped |
| every cheaper loser names why | integration (`genBrainAtom.route` case1): each endpoint ranked above the served one, and not in the attempt list, has a verdict other than `qualified` — live, 2026-10-01 green | the report is dropped, or the rank and the qualify disagree |
| the rank follows the ask | unit (`getAllQualifiedEndpoints.test.ts`): one fixture, two token estimates (input-heavy, output-heavy), two different heads — green | the rank goes back to a fixed blended price |
