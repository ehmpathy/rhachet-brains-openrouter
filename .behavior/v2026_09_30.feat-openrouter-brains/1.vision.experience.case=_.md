# 1.vision.experience.case=_ — the inventory

axes: `1.vision.experience.dimensions.md`. care = freq × cost; a rare path whose wrong answer is
unrecoverable is a critipath. each row is one outcome class. its tuple (A·M·B·C·D·E, then F
where the walk reads it — six positions mean F is collapsed) is one representative cell; "same for" lists the axes (or values) that map to the same case, exactly as
the per-failure-point walk table assigns them.

every critipath carries a **proof & clamp** section in its demo: the test that proves it, and
the change that turns that test red.

## forbidden cells — rejection invariants

| cell | why forbidden |
|---|---|
| a malformed filter reaches openrouter | each is a typo that would bill a wrong route; parse refuses (case=3) |
| a filtered ask sent without a pinned endpoint | an unpinned call routes via openrouter's balancer, outside the promises the caller wrote. a bare ask is unpinned by design (F10, ruled) |
| `allow_fallbacks: true` on any filtered ask | a fallback leaves the qualified set; probe 2 fell 8 places pricier |
| zero qualified endpoints, ask sent anyway | "never a silent route to some other provider" |
| `privacy=full` honored by `data_collection: deny` alone | probe 1: `deny` served AtlasCloud, off the zdr list |
| `region=usa` qualified by a base tag | a provider's domicile is not its datacenter |
| an answer returned from a provider other than the pinned one | the promise already broke; the caller must not read it (case=22) |
| an answer returned when the reply names no provider | the pin cannot be proven, so the caller would believe a promise no one checked (case=22 `[t2]`) |
| a `price.max` ask without `max_price` | the caller's bound would be a hope, not a refusal before spend |
| a pattern listed as a brain, or chosen | a pattern names no model (case=20 `[t3]`, case=6) |
| a 429 or 402 swallowed, or retried with a pause | failhide; a fleet would spin on a spent key |
