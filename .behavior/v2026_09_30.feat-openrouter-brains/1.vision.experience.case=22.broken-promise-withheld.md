# case=22 — a broken promise is withheld, not returned

**feel** sharp · **care** critipath (rare, and unrecoverable if silent: a zero-retention caller
who gets an answer from elsewhere has already leaked)

## narrative

dana runs `openrouter/deepseek/flash/privacy=full`. one day openrouter, for reasons of its own,
serves an ask from a provider other than the one pinned. the atom sees it in the response before
it returns: the answer is withheld, and dana's ask fails loud — which endpoint was pinned, which
provider served, which promise broke. dana's caller never reads text that broke the promise.

a reply can also name no provider at all (measured 2026-10-02: three review lanes). that proves
neither a breach nor a keep, so the pin cannot be proven. the atom withholds the answer under its
own name: `openrouter's reply named no provider, so the pin to '{endpoint}' cannot be proven`,
with the generation id for an audit. it never calls this a breach, and never reports a host of
`'null'`.

the gap, stated plainly: on `region=usa`, if openrouter served from the same provider's base
endpoint (`fireworks`, not `fireworks/us`), the response still names `Fireworks`, so the check
passes. that miss is trusted, not caught (F14, ruled). dana's auditor can find it later: every
answer carries `metrics.route.generationId`, and the record behind it names the served
`endpoint_id`.

## [tn] sketch

```
given('[case22] a pinned endpoint and a response that names another provider')
  when('[t0] dana asks')
    then('MalfunctionError: openrouter served {provider}, pinned {endpoint}; promise {word} broken')
    then('the answer text is absent from the error and from the return')
given('[case22] a pinned endpoint and a response that names no provider')
  when('[t2] dana asks')
    then('MalfunctionError: the reply named no provider, so the pin cannot be proven')
    then('it is never called a breach; the generation id rides in the error')
given('[case22] region=usa; the response names the pinned provider')
  when('[t1] dana asks region=usa')
    then('the answer returns at once; no generation read')
    then('metrics.route.generationId is set, so an auditor can read the served endpoint_id later')
```

## proof & clamp

| promise | proven by | clamp — goes red when |
|---|---|---|
| provider mismatch withheld | unit test on the check transformer: a response with a foreign `provider` → error, no output | the check is removed or demoted to a log line |
| a reply with no provider is withheld under its own name | `route/getOneServedEndpoint.test.ts` (`an answer that names no provider is withheld, and never called a breach`); `route/getOneRoutedCompletion.test.ts` (a failed reply with no provider is named as a failed reply) | a null provider passes the gate, or reads as `served from 'null'` |
| the gate compares like with like (Q20) | integration test pins each qualified endpoint of deepseek/flash once; asserts response `provider` = that endpoint's `provider_name` | openrouter's two names drift apart — the gate would withhold every answer, loud, never pass a wrong one |
| the audit id rides along | unit test: every returned answer carries `generationId` from the response `id` | the id is dropped |
| no background work | integration test: an ask resolves with no open timers or fetches left after it returns | an async audit is reintroduced |

a live repro of an openrouter mis-route is not available on demand, so the check is clamped on
recorded responses captured from the real api (probe 2), never on hand-written shapes.
