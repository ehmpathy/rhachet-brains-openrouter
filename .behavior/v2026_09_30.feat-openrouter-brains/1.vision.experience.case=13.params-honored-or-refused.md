# case=13 — an endpoint cannot honor the schema

**feel** sharp · **care** critipath (every ask that wants an object sends a schema, and `floor`
steers to the cheapest endpoint — measured: relace, the cheapest, lacks `response_format`)

## narrative

kai asks for a `z.object` on `openrouter/deepseek/flash/floor`. the walk drops every endpoint
whose `supported_parameters` lacks `response_format` before it ranks by price, so kai's ask pins
the cheapest endpoint that can honor the schema (dekallm on 2026-10-01; never relace). kai gets
a parsed object, never prose where an object should be. on a model where no endpoint supports
it, kai gets the funnel of case=4 with `response_format` as the step that emptied it, and a fix
line that names the ask, not the slug: switch to `z.string()` or another model.

## [tn] sketch

```
given('[case13] an ask with a structured output schema on a floor slug')
  when('[t0] kai asks, and the cheapest endpoint lacks response_format')
    then('the pinned endpoint is the cheapest one that lists response_format')
    then('kai receives a parsed object')
    then('the request carried provider.require_parameters = true, as a backstop')
  when('[t1] kai asks a model whose endpoints all lack response_format')
    then('BadRequestError (caller must fix): the funnel hits 0 at supports(response_format); the fix line names z.string()')
    then('no chat completion request was sent')
  when('[t2] kai asks on an endpoint that lists response_format, yet openrouter refuses it (404, no endpoint can handle)')
    then('the walk treats it as a fast refusal and hops to the next endpoint')
  when('[t3] kai asks for a z.string() reply on the same slug (F21)')
    then('no response_format is sent, and none is required')
    then('an endpoint without response_format may win: measured 2026-10-01, a 22k-token text ask pinned relace')
```
